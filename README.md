# Boardima — iOS Application

## Project Overview

Boardima is an iOS application developed using Swift and SwiftUI to help university students discover boarding accommodation and meal options.

## Technologies

- Swift and SwiftUI
- Firebase Authentication
- Cloud Firestore
- MapKit and Core Location
- Core ML
- WidgetKit
- Native iOS image processing for boarding poster QR codes

## Running the Application

1. Open `Boardima.xcodeproj` in Xcode.
2. Allow Swift Package Manager dependencies to resolve.
3. Add the correct `GoogleService-Info.plist` to the application target if it is not already present.
4. Select the `Boardima` scheme.
5. Select a compatible iPhone Simulator.
6. Press `Command + R` to build and run.

## Testing

Select the `Boardima` scheme and run the available automated tests using `Command + U`.
